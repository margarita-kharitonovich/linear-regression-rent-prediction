# Housing Rent Price Prediction using Linear Regression

## Project Overview
This project explores the application of linear regression for predicting housing rent prices based on property characteristics such as area and distance to the city center.

The implementation includes both simple linear regression (one feature) and multiple linear regression (two features), built from scratch using gradient descent optimization.

---

## Goal
The main goal of this project is to demonstrate how linear regression works in practice and how different features affect housing price prediction.

---

## Methodology

The project includes the following steps:

- Data generation and simulation
- Simple linear regression (1 feature: apartment area)
- Multiple linear regression (2 features: area, distance to center)
- Gradient descent optimization
- Mean Squared Error (MSE) minimization
- Data visualization (2D and 3D plots)

---

## Models

- Linear Regression (1 variable)
- Multiple Linear Regression (2 variables)
- Gradient Descent optimization (implemented manually)
